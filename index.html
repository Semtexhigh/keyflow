Where your data lives

Three places. You can name all of them.

Most password managers answer this question with a brand name. Keyflow answers it with a file path, a folder, and a row you can check.

  • The file

    One .vault file, encrypted, wherever you put it. Put it in iCloud Drive and your Mac and your phone both have it. No step two.

  • This computer

    An encrypted duplicate so the app opens without hunting for the file. Switchable off. Your PIN and fingerprint live only here and are never written into the file.

  • A server, if you want one

    Off by default. Switched on, an encrypted blob goes up so a dead laptop is recoverable from the master password alone. The server holds ciphertext and cannot read it.

Checked, not claimed

It tests each place and tells you.

A tick means the app wrote a test file into that folder and deleted it, and found the provider’s sync process running. Not that a setting is switched on.

No operating system will tell an app whether a cloud upload has actually finished. The panel says that out loud rather than showing you a hopeful tick.

How it looks

Black and white. Nothing to tune.

One look: white on pitch black, the same object as the app itself. No themes and no accent colours — nothing to pick but the text size, if you want the type larger.

The one thing you choose is the app icon: five marks — a cube (the default), the Keyflow key, a trading chart, a trend line, a red smiley — or a picture of your own, on a dark or light tile. It changes the lock screen and the browser tab on the spot, and one saved file carries it into the next build so the icon in your dock matches.

Unlocking with a PIN takes about sixty milliseconds. Switching tabs is immediate. Those are measured numbers, not impressions.

Before you download it

The things that will annoy you.

Better you read them here than find them out later.

There is no password recovery
Not a policy. There is no mechanism: nobody holds a copy of your key, so nobody can reset it. Write the master password down somewhere physical before you put anything important in.
macOS will warn you once
The app is not code-signed, because that costs a yearly fee to Apple. The one-paste command-line install clears that flag for you so you never see the prompt. If you download the app by hand instead: on an Intel Mac, right-click the app and choose Open, then Open again — once only. On Apple Silicon macOS may say the app is “damaged”: that is the same unsigned warning, not a real problem — run xattr -dr com.apple.quarantine /Applications/Keyflow.app once and open it normally. Windows SmartScreen: More info, then Run anyway.
Touch ID does not work on Linux
The system web view on Linux ships no passkey support at all. On macOS and Windows the blocker that prevented it is gone, but that has not yet been confirmed on real hardware. The app says which case you are in rather than offering a button that fails.
Anyone who can read this computer can get the PIN
The PIN is a convenience on a machine you trust. It opens the vault instantly and dies after ten wrong tries, and it never leaves the device, so a stolen file or server dump has no PIN in it to attack. Your master password is the actual lock.
